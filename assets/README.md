# 应用图标

这个文件夹包含应用的图标文件。

## 需要的图标格式：

- **Windows**: icon.ico (256x256 或更高)
- **macOS**: icon.icns (512x512 或更高)  
- **Linux**: icon.png (512x512 或更高)

## 如何添加图标：

1. 准备一个高质量的PNG图标 (至少512x512像素)
2. 使用在线工具或软件转换为所需格式：
   - Windows: 转换为.ico格式
   - macOS: 转换为.icns格式
   - Linux: 保持.png格式

3. 将文件放在此目录下，命名为：
   - icon.ico (Windows)
   - icon.icns (macOS)
   - icon.png (Linux)

## 临时解决方案：

如果暂时没有图标，应用会使用默认的Electron图标。
