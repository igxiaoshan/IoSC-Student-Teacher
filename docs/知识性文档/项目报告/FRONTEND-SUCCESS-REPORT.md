## 🚀 如何使用

### 1. 启动系统
```bash
# 启动前端 (端口3000)
cd frontend
npm start

# 启动后端 (端口5000)
cd backend
npm start
```

### 2. 访问AI功能
1. 打开浏览器访问: http://localhost:3000
2. 登录学生账户
3. 在侧边栏找到 "AI Learning Assistant" 菜单
4. 点击进入各个AI功能模块

### 3. 功能测试
- **学习助手**: 尝试问AI学习问题
- **智能练习**: 配置并开始练习
- **学习路径**: 生成个性化学习计划
- **学习伙伴**: 与AI伙伴聊天互动
