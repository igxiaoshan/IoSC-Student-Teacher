# 开源代码与组件使用说明及安装指南

## 一、项目概述

本项目为**学校管理系统**（School Management System），基于 MERN 技术栈开发，并通过 Electron 打包为跨平台桌面应用程序。系统支持管理员、教师、学生三种角色，提供考勤管理、成绩评估、AI 辅助教学等功能。

- **项目名称**: 学校管理系统
- **版本**: 1.0.0
- **许可证**: MIT License
- **技术架构**: MongoDB + Express.js + React.js + Node.js + Electron

## 三、安装说明

### 3.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|----------|
| **操作系统** | Windows 10 / macOS 10.15 / Ubuntu 18.04 | Windows 11 / macOS 13 / Ubuntu 22.04 |
| **Node.js** | v16.0.0 | v18.0.0 或 v20.0.0 |
| **npm** | v8.0.0 | v9.0.0 或 v10.0.0 |
| **MongoDB** | v4.4 | v6.0 或 v7.0 |
| **内存** | 4 GB | 8 GB 以上 |
| **磁盘空间** | 2 GB | 5 GB 以上 |

### 3.2 环境准备

#### 3.2.1 安装 Node.js

**Windows**:
1. 访问 https://nodejs.org 下载 LTS 版本安装包
2. 运行安装程序，按提示完成安装
3. 打开命令行验证：
   ```bash
   node --version
   npm --version
   ```

**macOS**:
```bash
# 使用 Homebrew 安装
brew install node@18
```

**Linux (Ubuntu/Debian)**:
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
```

#### 3.2.2 安装 MongoDB

**Windows**:
1. 访问 https://www.mongodb.com/try/download/community 下载安装包
2. 运行安装程序，选择完整安装
3. 将 MongoDB 添加到系统服务（推荐）
4. 验证安装：
   ```bash
   mongod --version
   ```

**macOS**:
```bash
brew tap mongodb/brew
brew install mongodb-community@6.0
brew services start mongodb/brew/mongodb-community
```

**Linux (Ubuntu)**:
```bash
# 导入 MongoDB 公钥
curl -fsSL https://www.mongodb.org/static/pgp/server-6.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-6.0.gpg --dearmor

# 添加 MongoDB 源
echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-6.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list

# 安装
sudo apt update
sudo apt install -y mongodb-org

# 启动服务
sudo systemctl start mongod
sudo systemctl enable mongod
```

### 3.3 项目安装

#### 3.3.1 克隆项目

```bash
git clone https://github.com/IoscEdc/IoSC-Student-Teacher.git
cd IoSC-Student-Teacher
```

#### 3.3.2 安装依赖

```bash
# 安装根目录依赖（Electron 相关）
npm install

# 安装后端依赖
cd backend
npm install

# 安装前端依赖
cd ../frontend
npm install

# 返回项目根目录
cd ..
```

**国内用户加速**:
```bash
# 设置 npm 镜像
npm run setup-mirrors

# 或手动设置
npm config set registry https://registry.npmmirror.com/
npm config set electron_mirror https://npmmirror.com/mirrors/electron/
```

#### 3.3.3 配置环境变量

**后端配置** (`backend/.env`):
```bash
# 复制示例配置
cp backend/.env.example backend/.env

# 编辑配置文件
# Windows
notepad backend/.env
# macOS/Linux
nano backend/.env
```

**必填配置项**:
```env
# 数据库连接
MONGO_URL=mongodb://127.0.0.1/school

# 服务器端口
PORT=5000
NODE_ENV=development
```

**可选 AI 服务配置**:
```env
# Dify API（AI 课件功能）
DIFY_BASE_URL=https://api.dify.ai
DIFY_API_KEY=your_dify_api_key

# Ollama（本地 AI）
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=deepseek-r1

# 即梦 AI（图像/视频生成）
JIMENG_API_URL=https://visual.volcengineapi.com
VOLC_ACCESS_KEY=your_access_key
VOLC_SECRET_KEY=your_secret_key
```

**前端配置** (`frontend/.env`):
```bash
# 复制示例配置
cp frontend/.env.example frontend/.env
```

**前端必填配置**:
```env
REACT_APP_BASE_URL=http://localhost:5000
```

### 3.4 启动应用

#### 3.4.1 开发模式（推荐）

**方式一：一键启动（Electron 开发模式）**
```bash
# 在项目根目录执行
npm run electron-dev
```
此命令会并行启动后端、前端和 Electron 窗口。

**方式二：分别启动**
```bash
# 终端 1 - 启动后端
cd backend
npm start

# 终端 2 - 启动前端
cd frontend
npm start

# 终端 3 - 启动 Electron（可选）
npm run electron
```

访问地址：
- 前端界面: http://localhost:3000
- 后端 API: http://localhost:5000

#### 3.4.2 生产模式

```bash
# 构建前端生产版本
npm run build:frontend

# 启动后端（生产模式）
cd backend
NODE_ENV=production npm start
```

### 3.5 打包桌面应用

#### 3.5.1 构建准备

```bash
# 确保已安装所有依赖
npm install
cd backend && npm install && cd ..
cd frontend && npm install && cd ..

# 构建前端
npm run build:frontend
```

#### 3.5.2 打包命令

```bash
# Windows 便携版（无需签名）
npm run build-nosign

# Windows 安装版
npm run dist:win

# macOS
npm run dist:mac

# Linux
npm run dist:linux
```

打包产物位于 `dist/` 目录。

### 3.6 首次运行

1. 启动应用后，访问 http://localhost:3000
2. 点击 **注册** 创建管理员账户
3. 使用管理员账户登录
4. 在管理面板中添加教师、学生、班级和科目数据

## 四、常见问题排查

### 4.1 网络连接错误

**症状**: 前端显示 "Network Error" 或无法连接后端

**解决方案**:
1. 确认后端服务已启动（检查 http://localhost:5000）
2. 检查 `frontend/.env` 中的 `REACT_APP_BASE_URL` 配置
3. 若仍有问题，修改 `frontend/src/redux/userRelated/userHandle.js`：
   ```javascript
   const REACT_APP_BASE_URL = "http://localhost:5000";
   // 将文件中所有 process.env.REACT_APP_BASE_URL 替换为 REACT_APP_BASE_URL
   ```

### 4.2 MongoDB 连接失败

**症状**: 后端启动时报 "MongoNetworkError"

**解决方案**:
1. 确认 MongoDB 服务已启动
   ```bash
   # Windows
   net start MongoDB

   # macOS
   brew services start mongodb-community

   # Linux
   sudo systemctl start mongod
   ```
2. 检查 `backend/.env` 中的 `MONGO_URL` 配置

### 4.3 Electron 打包失败

**症状**: `electron-builder` 报错

**解决方案**:
1. 下载 Electron 二进制：
   ```bash
   npm run download-electron
   ```
2. 清理缓存重新打包：
   ```bash
   npm run clean
   npm run build-nosign
   ```

### 4.4 AI 功能无响应

**症状**: AI 相关功能返回错误或无数据

**解决方案**:
1. 检查 AI 服务配置是否正确
2. 若未配置 AI 服务，系统会返回模拟数据用于测试
3. 确认 API Key 有效且有足够配额
