# IoSC 智慧校园管理系统 — 项目概述

> **IoSC (Intelligent School Campus) Student-Teacher Management System**
> 基于 MERN 技术栈的智慧校园管理系统，集成多 AI 服务，通过 Electron 打包为桌面应用。

---

## 一、项目定位

面向学校场景的全功能管理平台，覆盖**管理员、教师、学生**三大角色的日常教学与管理需求。核心特色是深度集成多个 AI 服务（Dify、Gemini、Ollama、即梦AI），实现智能化课件生成、考核出题、学情分析、学习路径规划等能力。

## 六、AI 集成详述

项目集成了四种 AI 服务，各司其职：

### 6.1 Dify AI（云端 RAG 平台）

- **用途**: 核心教学 AI，负责课件生成、考核出题、学情分析、学习助手对话
- **通信**: REST API + SSE 流式
- **回退机制**: AI 不可用时使用本地题库（TensorFlow/Python/数学等）

### 6.2 Gemini（通用推理）

- **用途**: 通用 AI 推理、聊天
- **实现**: OpenAI 兼容 SDK
- **端点**: `/api/gemini`

### 6.3 Ollama（本地推理）

- **用途**: 本地部署的 AI 推理能力
- **配置**: 通过 `aiConfig.js` 统一管理

### 6.4 即梦AI（火山引擎视觉生成）

- **用途**: 文生图、文生视频
- **认证**: HMAC-SHA256 签名
- **模型**: `jimeng_t2i_v40` (生图)、`jimeng_t2v_v30` (生视频)

### 6.5 多模型工作流

- **文件**: `backend/services/multiModelWorkflow.js`
- **端点**: `/api/workflow/*`
- **功能**: 代码审查、功能开发、调试、API/Schema 设计、测试生成
- **工具链**: 集成 Ace-Tool MCP（语义搜索）和 Grok-Search MCP（网络搜索）

## 十一、安全特性

- **密码加密**: bcrypt 哈希存储
- **数据过滤**: 自动移除响应中的密码字段
- **CORS**: 跨域安全配置
- **限流**: express-rate-limit 请求频率限制
- **文件验证**: multer 文件上传类型和大小限制
- **错误处理**: 全局错误中间件，统一响应格式
- **优雅关闭**: SIGTERM/SIGINT 信号处理
