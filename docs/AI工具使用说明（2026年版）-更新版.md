## 各AI工具详细说明

### 1. 即梦AI (Jimeng) - 视觉内容生成

**技术架构：**
- **API来源**：火山引擎视觉生成服务
- **接入方式**：后端服务层封装 (`backend/services/jimengService.js`)
- **前端调用**：`frontend/src/utils/jimengAPI.js`

**功能模块：**
| 功能 | 模型版本 | 用途 |
|:---|:---|:---|
| 文生图 | 即梦4.0 (`jimeng_t2i_v40`) | 教学插图、微课背景、知识卡片 |
| 文生视频 | 即梦3.0 (`jimeng_t2v_v30`) | 教学演示视频片段 |

**关键代码示例：**
```javascript
// 文生图调用
jimengAPI.textToImage(prompt, {
    width: 1024,
    height: 1024,
    scale: 0.7  // 文本影响程度
});
```

**采纳说明**：AI生成素材经人工筛选后使用，主要解决教学资源制作效率问题。

---

### 2. DeepSeek-R1（通过Dify平台） - 智能教学助手

**技术架构：**
- **模型来源**：DeepSeek-R1 深度求索
- **接入方式**：通过Dify云平台统一接入
- **服务封装**：`backend/services/difyService.js`

**架构流程：**
```
前端AI组件 → Express中间件 → Dify服务层 → Dify云平台 → DeepSeek-R1模型
```

**功能模块：**

#### 教师端功能
| 功能 | API端点 | 说明 |
|:---|:---|:---|
| 智能备课 | `POST /api/teacher-ai/lesson-plan/:teacherId` | 基于课程大纲生成教学计划 |
| 考核生成 | `POST /api/teacher-ai/exam-content/:teacherId` | 自动生成题目和参考答案 |
| 学情分析 | `POST /api/teacher-ai/analytics/:teacherId` | 分析学生答案提供教学建议 |

#### 学生端功能
| 功能 | API端点 | 说明 |
|:---|:---|:---|
| 学习助手 | `POST /api/student/ai/ask` | 结合教学内容解答问题 |
| 练习评测 | `POST /api/student/ai/practice/generate` | 生成个性化练习并纠错 |

**配置说明：**
```env
# Dify平台配置
DIFY_API_URL=https://api.dify.ai/v1
DIFY_API_KEY=your_dify_api_key

# 应用配置
DIFY_TEACHER_LESSON_APP_ID=xxx      # 智能备课助手
DIFY_TEACHER_EXAM_APP_ID=xxx        # 考核内容生成
DIFY_STUDENT_LEARNING_APP_ID=xxx    # 学习助手
DIFY_STUDENT_PRACTICE_APP_ID=xxx    # 练习评测助手
```

**关键代码示例：**
```javascript
// 智能备课调用
const response = await difyService.generateLessonPlan({
    subject: 'TensorFlow',
    topic: '神经网络基础',
    duration: 45,
    studentLevel: 'intermediate'
});

// 学习助手调用
const answer = await difyService.answerStudentQuestion(
    studentId,
    '解释一下TensorFlow.js的工作原理',
    { subjectName: '深度学习' }
);
```

**采纳说明**：
- 教师端功能生成的教学方案经人工审核后采纳
- 学生端功能仅用于验证课件准确性，不参与系统开发
